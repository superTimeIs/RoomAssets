# Отчёт по проекту Room & Assets

## Что сделано во фронтенде
- Стек: Vite + Svelte + TypeScript
- Библиотеки: axios (сетевые запросы), MSW (моки), clsx (классы)
- Структура: компоненты (Button, Header, RoomsTable), API-слой, моки
- Состояние: пока локальное (useState-аналог в Svelte), позже — контекст
- Обработка ошибок: try/catch в запросах, вывод ошибки в UI

## Что сделано в бэкенде
- Пока нет бэкенда. Данные имитируются через MSW (Mock Service Worker).
- В следующих лабах будет Fastify + Prisma + PostgreSQL.

## CI/CD
- Пока не настроен. В следующих лабах — GitHub Actions + GitHub Pages + Render.

## Что было интересно
- Настройка моков через MSW — интересно, как можно имитировать сервер без бэкенда.

## Пожелания
- Хотелось бы больше примеров для Svelte (в лабах только React).
